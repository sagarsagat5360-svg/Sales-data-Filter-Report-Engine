# Sales Data Filter & Report Engine

A beginner-friendly NumPy project that simulates a year of sales for 10 stores across 12 months, filters the data, and generates monthly and store-wise reports.

## Features

- Generates a 10 × 12 sales matrix.
- Uses month labels and store names.
- Slices quarterly and store-specific sales.
- Uses Boolean masking with `&`, `|`, and `~`.
- Uses fancy indexing to select stores and top-performing months.
- Builds growth targets with `numpy.linspace`.
- Prints monthly, store-wise, and overall summary reports.

## Requirements

- Python 3.9+
- NumPy

Install NumPy:

```bash
python -m pip install numpy
```

## Run locally

```bash
python sales_report_engine.py
```

## Run on Google Colab

1. Open Google Colab.
2. Create a new notebook.
3. Copy the contents of `sales_report_engine.py` into a code cell.
4. Run the cell. Colab usually already includes NumPy.

## Data layout

The `sales` array has shape `(10, 12)`:
- Each row represents one store.
- Each column represents one month.
- Example: `sales[0, :]` selects all 12 months for Store_1.
- Example: `sales[:, 0:3]` selects January to March for every store.

## Important note about targets

The targets are illustrative and can be adjusted. The monthly target in the filtering section is based on the average sales across stores plus ₹5,000. The report section uses growth rates from 3% to 8% generated by `np.linspace`.
